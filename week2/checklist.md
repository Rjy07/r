# 第二周 · Claude Code 安装与配置 · 操作清单

> 配套正文：[ClaudeCode安装与配置.md](ClaudeCode安装与配置.md)
> 用法：按编号从上到下操作，每步先做「操作」，再对照「结果」。结果不符时看「避免」，不要跳步。
> 图号对应正文截图，点击可查看。

## A. 安装 Claude Code 插件

| # | 操作                                                                                                       | 结果                                                                                                       | 避免                                                                                                           |
| - | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 1 | 确认第一周的 VS Code 能正常启动、能运行 C 程序                                                             | VS Code 正常打开                                                                                           | 第一周环境没跑通就继续本周                                                                                     |
| 2 | `Ctrl + Shift + X` 打开扩展面板 → 搜索 `claude code`                                                  | 出现插件搜索结果（[图 1](images/01-vscode-claude-extension.png)）                                           | 看到名字里有 Claude Code 就直接点安装                                                                          |
| 3 | 只选 **Claude Code for VS Code**、发布者是 **Anthropic**（带蓝色认证勾）的那一项 → 点「安装」 | 安装按钮变为「更新 / 禁用 / 卸载」，左侧活动栏出现星芒图标（[图 1](images/01-vscode-claude-extension.png)） | 装「Claude Code YOLO」「[非官方] Claude Code」「Claude Code Assist」等第三方插件；额外去装 CLI（本课程不需要） |
| 4 | 重新启动vscode                                                                                             | 重启后星芒图标仍在活动栏                                                                                   | 不重启就打开面板；VS Code 版本低于 1.94.0                                                                      |

## B. 安装 CC Switch

| # | 操作                                                                                                                               | 结果                                                                 | 避免                                                          |
| - | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------- |
| 5 | 打开 [https://ccswitch.io/zh/](https://ccswitch.io/zh/) 或其 GitHub Releases → 下载 `CC-Switch-v4.0.9-Windows.msi`（约 15.8 MB） | 得到一个 `.msi` 安装包（[图 2](images/02-ccswitch-website.png)）    | 下载 `arm64` 或 Portable 版；从付费、要求充值的仿冒网站下载 |
| 6 | 双击 `.msi` → UAC 点「是」→ 一路「下一步」完成安装 → 启动 CC Switch                                                           | 出现 CC Switch 主界面（[图 3](images/03-ccswitch-main-ui.png)）       | 装完不启动；把 CC Switch 当成模型服务或 AI 工具               |
| 7 | 在顶部一排图标中点击 **Claude Code 的星芒图标**                                                                              | 该图标显示为选中状态（[图 3](images/03-ccswitch-main-ui.png) 箭头 1） | 选成 Codex 或 Gemini，配置会写到别的工具里                    |

## C. 获取 ModelScope 访问令牌（其他平台（如deepseek）的api都可以）

| # | 操作                                                                                                                     | 结果                                                                                | 避免                                                      |
| - | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- | --------------------------------------------------------- |
| 8 | 打开 [https://www.modelscope.cn](https://www.modelscope.cn) → 注册并登录 → 按页面提示**绑定阿里云账号**并完成实名 | 登录成功，账号已完成绑定                                                            | 跳过绑定阿里云；使用别人的账号                            |
| 9 | 右上角头像 → 个人中心 → **账号设置** → 左侧 **访问令牌** → **新建访问令牌** → 点复制              | 得到一串 `ms-` 开头的令牌并已复制（[图 5](images/05-modelscope-access-token.png)） | 把令牌发群里、截进图里、传上 GitHub；发现泄露后不删除重建 |

## D. 在 CC Switch 中配置 ModelScope

| #  | 操作                                                                                                                                    | 结果                                                                     | 避免                                                                |
| -- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| 10 | 点右上角 **`+`** → 确认在 **Claude 供应商**页签 → 搜索 `modelscope` → 选中 **ModelScope** 预设                 | 下方表单自动填好大部分内容（[图 6](images/06-ccswitch-add-provider.png)） | 在错误页签里配置；不选预设、全部手填                                |
| 11 | 在 **API Key** 中粘贴刚复制的令牌（前后不留空格）；检查请求地址是 `https://api-inference.modelscope.cn`；模型映射保持预设默认值 | 表单各字段完整（[图 7](images/07-ccswitch-provider-config.png)）          | 地址写成 `/v1` 结尾或末尾多加 `/`；手动改模型名；Key 前后带空格 |
| 12 | 点击右下角「保存」                                                                                                                      | 供应商卡片出现在列表中                                                   | 填完直接关窗，没有保存                                              |

## E. 测试、启用并验证

| #  | 操作                                                                                  | 结果                                                                                                              | 避免                                                   |
| -- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 13 | 把鼠标移到供应商卡片右侧按钮 → 点击**折线图标**测试连通                        | 顶部出现绿色提示「ModelScope 连通正常 (xxx ms)」，500ms 以内正常（[图 8](images/08-ccswitch-connection-test.png)） | 测试不通还继续；只重试不检查 Key、请求地址、阿里云绑定 |
| 14 | 点击卡片上的「启用」                                                                  | 卡片显示「使用中」（[图 8](images/08-ccswitch-connection-test.png)）                                               | 只保存不启用；顶部工具选错                             |
| 15 | 完全退出 VS Code（关闭所有窗口）→ 重新打开                                           | 启动后**不弹** Anthropic 登录页                                                                             | 只最小化或只关标签页；改完配置不重启                   |
| 16 | 点左侧星芒图标打开 Claude Code；图标不出现就点右下角状态栏的「Claude Code」           | 对话面板打开，底部显示 Qwen 等魔搭模型名（[图 9](images/09-vscode-claude-panel.png)）                              | 只打开文件夹、没打开文件时找不到图标；VS Code 版本过低 |
| 17 | 输入「你好，请用一句话介绍你自己，并告诉我你现在用的是哪个模型。」→ 回车             | 正常中文回复，底部模型名为魔搭模型                                                                                | 开 Auto mode 让它自动执行；把它的回答当成标准答案      |
| 18 | （作业用）记事本打开 `C:\Users\你的用户名\.claude\settings.json` → 找到 `env` 段 | 其中有 `ANTHROPIC_BASE_URL`，值为 `https://api-inference.modelscope.cn`                                       | 手动修改这个 JSON；把令牌内容贴到任何提交物里          |
